# Instrucciones locales · EL TAROT DE MARÍA

Estas instrucciones solo se aplican al trabajar dentro de esta carpeta.

- Usa `MEMORY.md` de esta carpeta como memoria del proyecto. Verifica en los archivos actuales cualquier dato que pueda haber cambiado.
- Mantén aquí únicamente información del juego. No incorpores datos de Atlas, Mireia, investigación académica, UAB u otros proyectos.
- No traslades notas del tarot a memorias de otros proyectos. Si el usuario pide guardar un aprendizaje del tarot, actualiza esta memoria local.
- Conserva el enlace público actual y el proyecto Sites existente al publicar cambios ordinarios; no crees otro sitio por defecto.
- Separa siempre lo publicado, lo probado localmente, lo preparado y lo pendiente. No presentes una app Android como compilada o publicada mientras no exista el paquete y la verificación correspondiente.
- Las preferencias generales de escritura del usuario siguen aplicándose; esta instrucción delimita solamente el contexto del proyecto.
